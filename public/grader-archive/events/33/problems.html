254275 OOP (Summer) - Mini Test 1

  • Problems
  • Submissions
  • Scores
A. Square and cube
Write a program that reads an integer and prints out its square (power of 2) and its cube (power of 3).
B. Countdown
Write a program that prints a countdown from x to 1 and then "boom", where x is input by the user.
C. Middle of three
Write a program that reads in 3 unsorted integers and outputs the middle number as if they were sorted.
D. Star slash
Write a program that draws a slash using stars of a given size.
E. A lot of As
Write a program that counts the number of As in one line of input.
F. Abbreviator
Write a program that reads in one word per line and generates an abbreviation. Print out the first letter of each word followed by a dot (.). The end of the input is marked by 3 stars (***).
