This lab explores prompt engineering and best practices for designing effective prompts to improve the quality of your LLM-generated responses. You'll learn how to craft prompts that are concise, specific, and well-defined, focusing on one task at a time. What can LLMs do?

Large Language Models (LLMs) are a revolutionary class of AI models capable of understanding, generating, and interacting with human language in incredibly sophisticated ways. They are trained on vast amounts of text data, allowing them to learn complex patterns, grammar, semantics, and even nuanced contexts.

Here's a high-level overview of what LLMs can do:

  • Text Generation: This is perhaps their most well-known capability. LLMs can write essays, articles, poems, stories, emails, marketing copy, and even scripts. Given a prompt, they can generate coherent and contextually relevant text in various styles and tones.
  • Question Answering: LLMs excel at retrieving and synthesizing information from their training data to answer a wide range of questions, from factual queries to more open-ended conceptual ones. They can act as powerful knowledge assistants.
  • Summarization, Rewriting and Paraphrasing: They can distill long documents, articles, or conversations into concise summaries, highlighting the key points and main ideas. They can rephrase existing text while maintaining its original meaning, useful for improving clarity, adapting to a different audience.
  • Language Translation: LLMs can translate text between numerous languages with remarkable accuracy, often capturing idiomatic expressions and cultural nuances better than traditional machine translation systems.
  • Code Generation and Assistance: For computer science students, this is a game-changer. LLMs can generate code snippets, functions, or even entire programs based on natural language descriptions. They can debug code by identifying errors and suggesting fixes, explain complex code sections in plain language and translate code between different programming languages.
  • Chatbots and Conversational AI: Powering intelligent conversational agents, LLMs enable chatbots to engage in natural, human-like dialogue, providing customer support, information, or even interactive storytelling.
  • Information Extraction: They can identify and extract specific entities (like names, dates, organizations) or structured information from unstructured text.

In essence, LLMs are incredibly versatile tools that process and generate text with an unprecedented level of human-like understanding. They are transforming how we interact with information, automate tasks, and create content across various domains, including the entire software development lifecycle.

Gemini

Gemini is a family of powerful generative AI models developed by Google DeepMind, capable of understanding and generating various forms of content, including text, code, images, audio, and video.

Gemini Models

Gemini Pro: Designed for complex reasoning, including:

  • Analyzing and summarizing large amounts of information.
  • Sophisticated cross-modal reasoning (across text, code, images, etc.).
  • Effective problem-solving with complex codebases.

Gemini Flash: Optimized for speed and efficiency, offering:

  • Sub-second response times and high throughput.
  • High quality at a lower cost for a wide range of tasks.
  • Enhanced multimodal capabilities, including improved spatial understanding, new output modalities (text, audio, images), and native tool use (Google Search, code execution, and third-party functions).

Streaming text output

Create a file named 2-text-streaming.py in your project and copy/paste the following contents:

2-text-streaming.py

import os
from google import genai

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

prompt = "เขียนสโลแกนสั้นๆ ที่สะดุดหูสำหรับร้านกาแฟที่เป็นมิตรกับสิ่งแวดล้อมแห่งใหม่"
print(f"Streaming response for prompt: '{prompt}'")
print("\nResponse:")
for chunk in client.models.generate_content_stream(
    model='gemini-2.5-flash', # Everyday model
    contents=prompt
):
    # Each chunk is a part of the response, print it as it arrives
    print(chunk.text, end="", flush=True) # Use end="" to avoid new lines

Structured text prompting

Create a file named 3-structured-text.py in your project and copy/paste the following contents:

3-structured-text.py

import os
from google import genai
from google.genai import types

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

structured_prompt = [
    types.Content(
        role="user",
        parts=[
            types.Part.from_text(text="เขียนสโลแกนสั้นๆ ที่สะดุดหูสำหรับร้านกาแฟที่เป็นมิตรกับสิ่งแวดล้อมแห่งใหม่")
        ]
    )
]
print(f"Sending structured prompt: {structured_prompt}")
response = client.models.generate_content(
    model='gemini-2.0-flash-lite',
    contents=structured_prompt,
    config=types.GenerateContentConfig(response_mime_type="text/plain")
)
print("\nResponse:")
print(response.text)

Run the script.

Configuring the safety settings

Create a file named 5-safety.py in your project and copy/paste the following contents:

5-safety.py

import os
from google import genai
from google.genai import types

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

prompt = "Write a list of 5 very rude phrases considered offensive. Do not include any explanations."
print(f"Sending prompt: '{prompt}'")
response = client.models.generate_content(
    model='gemini-2.0-flash-lite',
    contents=prompt,
    config = types.GenerateContentConfig(
        safety_settings=[
            types.SafetySetting(
              category=types.HarmCategory.HARM_CATEGORY_HATE_SPEECH,
              threshold=types.HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
            ),
            types.SafetySetting(
              category=types.HarmCategory.HARM_CATEGORY_HARASSMENT,
              threshold=types.HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
            ),
            types.SafetySetting(
              category=types.HarmCategory.HARM_CATEGORY_DANGEROUS_CONTENT,
              threshold=types.HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
            ),
            types.SafetySetting(
              category=types.HarmCategory.HARM_CATEGORY_SEXUALLY_EXPLICIT,
              threshold=types.HarmBlockThreshold.BLOCK_LOW_AND_ABOVE,
            )
        ]
    )
)
print("\nResponse:")
print(response.text)

print("\nFinish reason:", response.candidates[0].finish_reason)

Run the script. The "finish reason" is likely (but it is not deterministic) to output "SAFETY" meaning that the response is blocked by the configured safety settings.

Try setting some or all of the safety settings to BLOCK_NONE. Can you get a response?

Configuring thinking

Create a file named 7-thinking.py in your project and copy/paste the following contents:

7-thinking.py

import os
from google import genai
from google.genai import types

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

prompt = """
   How can you obtain 565 with 25 8 3 7 and 1?
   You can only use a number once.
   You can use addition, subtraction, multiplication, and division.
   If you cannot obtain the number, find the closest number you can obtain with the given numbers.
   Output the mathematical expression and what it equals.
   Do not include any words or explanation.
   Example output: (25 * 3) + 8 = 83
"""

response = client.models.generate_content(
  model='gemini-2.5-flash',
  contents=prompt,
  config=types.GenerateContentConfig(
    thinking_config=types.ThinkingConfig(
      thinking_budget=0,
      include_thoughts=True
    )
  )
)

for part in response.candidates[0].content.parts:
  if not part.text:
    continue
  if part.thought:
    print("Thought summary:")
    print(part.text)
    print()
  else:
    print("Answer:")
    print(part.text)
    print()

Run the script with no thinking (thinking_budget=0). Did the LLM output a correct response? Sometimes it will get it completely wrong! (You may need to run it a few times to see the variety of responses.)

Next, experiment with thinking by increasing the thinking_budget to 500 and then 2000. Do you get better answers?

LLMs are very good at outputting structured text data and therefore can be instructed to return JSON. The generate_content function can be configured to return JSON in a specified schema, defined using pydantic.

Create a file named 8-json.py in your project and copy/paste the following contents:

8-json.py

import json
import os
from google import genai
from google.genai import types
from pydantic import BaseModel

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

class Recipe(BaseModel):
    recipe_name: str
    recipe_description: str
    recipe_ingredients: list[str]

response = client.models.generate_content(
    model='gemini-2.0-flash-lite',
    contents="Provide a popular som tam recipe and its ingredients.",
    config=types.GenerateContentConfig(
        response_mime_type="application/json",
        response_schema=Recipe,
    ),
)

print(json.dumps(json.loads(response.text), indent=4))

Run the script.

Returning structured data is one of the key features used in multi-agent systems (coming later) to pass data between agents.

Create a file named 9-tokens.py in your project and copy/paste the following contents:

9-tokens.py

import os
from google import genai

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

models = {
    'gemini-2.0-flash-lite': {
        'description': 'Fast, cheap model for text generation',
        'input_cost_usd_per_token': 0.075 / 1000000,  # $0.075 per million tokens
        'output_cost_usd_per_token': 0.3 / 1000000  # $0.30 per million tokens
    },
    'gemini-2.5-flash': {
        'description': 'Everyday model',
        'input_cost_usd_per_token': 0.3 / 1000000,  # $0.30 per million tokens
        'output_cost_usd_per_token': 2.5 / 1000000  # $2.50 per million tokens
    },
    'gemini-2.5-pro': {
        'description': 'High quality, expensive model',
        'input_cost_usd_per_token': 1.25 / 1000000,  # $1.25 per million tokens
        'output_cost_usd_per_token': 10 / 1000000  # $10.00 per million tokens
    }
}
selected_model = 'gemini-2.0-flash-lite'

prompt = "เขียนสโลแกนสั้นๆ ที่สะดุดหูสำหรับร้านกาแฟที่เป็นมิตรกับสิ่งแวดล้อมแห่งใหม่"
print(f"Sending prompt: '{prompt}'")
response = client.models.generate_content(
    model=selected_model,
    contents=prompt
)
print("\nResponse:")
print(response.text)

input_tokens = response.usage_metadata.prompt_token_count
input_cost = input_tokens * float(models[selected_model]['input_cost_usd_per_token'])
print(f"Prompt tokens: {input_tokens} (cost ${input_cost:.6f})")
output_tokens = response.usage_metadata.candidates_token_count
output_cost = output_tokens * float(models[selected_model]['output_cost_usd_per_token'])
print(f"Output tokens: {output_tokens} (cost ${output_cost:.6f})")
total_tokens = response.usage_metadata.total_token_count
print(f"Total tokens: {total_tokens} (cost ${input_cost+output_cost:.6f})")

Try running the script 3 times, changing the selected_model each time. There is a big difference in cost between the flash and pro models.

Note: The 2.5 flash and 2.5 pro models have thinking enabled by default. This adds a lot of extra tokens, thus increasing the cost.

Imagine building an agent that makes multiple calls to a model, and then imagine 100s of users calling the agent. Costs are likely to escalate quickly. Through clever model configuration and prompt engineering, we can minimise the cost of our model calls.

Create a file named 10-chat.py in your project and copy/paste the following contents:

10-chat.py

import os
from google import genai
from google.genai import types

client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

system_instruction = """
  You are an expert software developer and a helpful coding assistant.
  You are able to generate high-quality code in any programming language.
"""

chat_config = types.GenerateContentConfig(
    system_instruction=system_instruction,
)

chat = client.chats.create(
    model='gemini-2.0-flash-lite',
    config=chat_config,
)

while True:
    user_input = input("User: ")
    if user_input.lower() in ["exit", "quit"]:
        print("Exiting chat.")
        break

    response = chat.send_message(user_input)

    print(f"Assistant: {response.text}")

Run the script. The difference between chat and regular prompting is that in a chat, the LLM has the whole conversation as input. For example, send the following questions to chat in order, notice how it's able to answer based on the context.

  1. Write a function in Python to calculate Fibonacci.
  2. Convert it to Javascript.
  3. Make the code as concise as possible.
  4. Write a unit test for the function.

Note: The chat mode is how you talk to ChatGPT or Gemini on the web.
